# StockFinder Landing Page

Landing page minimalista para StockFinder - Comparador de precios de componentes de PC.

## Características

- ✨ Diseño minimalista y responsive
- 🚀 HTML puro sin dependencias
- 📱 Optimizado para todos los dispositivos
- ⚡ Carga ultra-rápida
- 🌐 Desplegado en GitHub Pages

## Deployment en GitHub Pages

Esta página está configurada para desplegarse automáticamente en GitHub Pages.

### Configuración

1. Ve a Settings → Pages en tu repositorio de GitHub
2. En "Source", selecciona la rama `main`
3. En "Folder", selecciona `/ (root)`
4. Guarda los cambios

Tu sitio estará disponible en: `https://mdaniel592.github.io/SF-Website/`

## Desarrollo Local

Simplemente abre `index.html` en tu navegador. No requiere servidor ni instalación de dependencias.

## Estructura

```
StockFinder/
├── index.html          # Landing page principal
├── public/            # Recursos estáticos (favicon, imágenes)
└── README.md          # Este archivo
```

## Características de la Landing Page

- **Compara Precios**: Encuentra los mejores precios en componentes
- **Alertas de Stock**: Notificaciones de disponibilidad y precios
- **PC Builder**: Herramienta para armar configuraciones
- **Múltiples Tiendas**: Comparación entre tiendas principales
- **Historial de Precios**: Visualización de evolución de precios
- **Ofertas en Tiempo Real**: Descubre ofertas flash
